# Foam templates

A Foam template is a pre-defined structure that can be used to create new notes in a consistent format. They can be used via the `Foam: Create Note from Template` command, which will prompt you to select a template and fill in any required fields.
This repository comes with four templates:

- **Daily note**: journaling or logging daily activities.
- **Regular note**: capturing information on a specific topic, project, meeting.
- **Index note**: creating `index.md` notes.
- **Context note**: creating `CONTEXT.md` notes.
